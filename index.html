Can a lab report predict a good wine?

This project uses 11 chemical measurements of Portuguese red wines to estimate whether expert tasters would rate a wine 7 out of 10 or higher. It covers the full path: cleaning the data, comparing models, explaining the result, and a live app.

The data

The UCI Wine Quality dataset (Cortez et al., 2009) describes red and white Vinho Verde wines from northern Portugal. This project uses the red wines: 1,599 samples, each with 11 physicochemical measurements and a quality score given by tasters. There are no missing values.

The 11 measurements

Fixed acidity, volatile acidity, citric acid, residual sugar, chlorides, free sulfur dioxide, total sulfur dioxide, density, pH, sulphates and alcohol.

Cleaning

240 rows were exact duplicates. They were removed before splitting, because a copy of the same wine in both the training and test sets would let the model see the answer and inflate its score. That left 1,359 wines.

Defining “good”

Scores run from 3 to 8 in this data, and most wines get 5 or 6. A wine counts as good at 7 or above: 184 wines, or 13.5%.

Source: Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality. UCI Machine Learning Repository. doi.org/10.24432/C56S3T. Licensed CC BY 4.0.

What the data shows

The correlation of each measurement with the quality score tells a simple story: stronger wines with more sulphates and less vinegar-like acidity score higher.

Findings

Alcohol has the strongest link to quality (r = 0.48), followed by volatile acidity in the other direction (r = −0.40). Residual sugar shows almost no relationship (r = 0.01).

Several measurements move together: fixed acidity with pH (−0.69), citric acid (0.67) and density (0.67), and free with total sulfur dioxide (0.67). This matters for model choice, because tree-based models cope with correlated inputs better than plain linear ones.

Why accuracy alone misleads: a model that calls every wine “not good” is right 86% of the time and finds no good wines at all. Results below are judged on precision, recall and F1 for the good class.

Models and results

Five models were compared with 5-fold cross-validation on the training set (1,087 wines), with class weights to handle the imbalance. The test set (272 wines) was kept untouched until the end.

Tuning with grid search lifted the Random Forest most, because shallower trees (depth 8, at least 5 samples per leaf) stopped it from memorising the training data. After tuning, the three leading models are within about 0.012 F1 of each other, so they perform comparably. The Random Forest was chosen because it can be explained feature by feature.

Choosing the cut-off

Good wines are rare, so the model rarely reaches 50% confidence. The cut-off was set to 0.37 using only training data, which raised cross-validated F1 from 0.518 to 0.534.

The model found 28 of 37 good wines (recall 0.76). When it said “good”, it was right 28 times out of 69 (precision 0.41). F1 for good wines is 0.53, close to the cross-validated 0.534, so there is no sign of overfitting.

Overall accuracy of 0.82 is lower than the do-nothing baseline of 0.86, and that is expected: the baseline never finds a good wine.

Limits

Quality scores come from human tasters and are noisy. The test set holds only 37 good wines, so each one moves recall by about 2.7 points. All wines are Portuguese Vinho Verde, so the model should not be applied to other wine styles.

Why the model says what it says

Two views of the final Random Forest: how much each measurement matters overall, and which way it pushes a prediction (from SHAP values on the test set).

These are patterns in this dataset, not proof that changing a measurement would change a wine’s rating. Density, for example, partly stands in for alcohol.

Wine gallery

Real wines from the dataset, each with the score tasters gave it and its main measurements. The dataset has no brand or grape names, so each wine appears as an anonymous sample number.

The glass on each card fills in proportion to its quality score. Scores run from 0 to 10, but this data only contains 3 to 8. “Good” means 7 or higher, the same definition the model uses. The model’s chance is illustrative, because some of these wines were part of its training data.
